# 需求草稿：建模模块对齐原型 + 全模块差异盘点

> 输入：用户直接指令（2026-10-07）——本体建模界面与高保真原型当前版本不一致（原型为卡片式本体管理 + 新建向导 + SVG 建模画布，生产端为纯表格）；请仔细对比并检查其他界面是否也非最新/未实现完整。

## 盘点结论（原型 ↔ 生产差异）

| 模块 | 原型形态 | 生产现状 | 差距 |
|---|---|---|---|
| 本体建模·本体管理 | 本体卡片 + 新建向导（三初始化路径） | 纯表格；**无创建本体能力（后端亦无接口）** | ❌ 本轮补齐 |
| 本体建模·设计器 | SVG 建模画布（节点/连线/拖拽/属性面板/AI 助手） | 注册中心表格写路径 | ❌ 本轮补画布（AI 助手对话为 Utopia/LLM 后续提案） |
| 数据资产·数据源中心 | tabs：列表/更新策略/探查/文档源 | tabs：结构化/文档源/探查；更新策略仅表单字段 | ⚠️ 本轮补「更新策略」tab |
| 其余模块（集市/工作台/知识/运行时/推理/沙盘/能力/治理/系统管理） | 页面均有对应 | 均已生产化（此前 complete-remaining-modules 等） | ✅ 形态等价（tab 组织略有差异） |

## 目标（生产级）

1. **创建本体（后端补齐）**：POST /api/v1/ontologies，幂等（客户端 id）；三种初始化：blank（仅元数据+创建者为所有者）/ template（供应链最小集：4 对象+3 关系画布草稿）/ reverse（从 table_profiles 表生成对象草稿，上限 4 张）。
2. **本体管理卡片化**：对齐原型的卡片网格（场景/版本/状态/成员/对象关系数、当前工作本体高亮）+ 新建向导（三路径，真实创建）。
3. **建模画布（新页 modeling/designer）**：SVG 画布渲染当前本体的画布对象与关系（贝塞尔连线+箭头+标签）；点击对象→属性面板（属性表/生命周期流转/查看实例）；点击关系→边属性；节点可拖拽（布局按本体存 localStorage）；工具栏：新建对象/关系（真实写）。
4. **数据源中心补「更新策略」tab**：表名/模式（行内切换 → 真实 PUT）/状态。
5. 菜单 seed 增加「本体设计器」叶子。

## 非目标
- AI 建模助手对话（LLM/Utopia 在线，后续提案）；
- 画布多选/框选/缩放平移（本轮单选+拖拽；交互增强后续提案）。
