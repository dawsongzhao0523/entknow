# 20261006 语义查询与检索

## 需求描述

原型 M5「推理演绎 · 语义查询」落地：

1. **统一检索 API**：一个关键字横跨对象（名称/英文/属性）、知识条目（标题/术语）、实例（实例号/属性值）、同义词组检索，分类返回。
2. **查询执行与历史**：提交自然语言问题 → 执行检索 → 生成确定性 DSL 展示（命中驱动的模板）→ 记录延迟/命中数/执行人；查询历史可查、可按人过滤；执行幂等（客户端 ID）。
3. **前端页面**：M5 语义查询页（查询输入 → 结果分区 + DSL + 延迟 + 历史表 + 一键重问）。

## 验收

- 检索：`订单` 命中对象「采购订单」与知识条目；`S-0012` 命中实例；`供货商` 命中同义词组。
- 执行：记录历史（问题/DSL/命中数/延迟/执行人）；同 ID 重复执行幂等（历史不重复）。
- 空 query 400；历史按 by 过滤。
- 集成测试覆盖；前端完成真实闭环。
