# 20261006 数据资产运营写路径

## 需求描述

原型 数据资产「数据资产」的运营写路径落地：

1. **数据源注册/编辑**：幂等注册（名称唯一，重名异 ID 409）；编辑连接/同步策略（NONE/CRON/CDC/EVENT）/敏感级/负责人；停用走状态切换。
2. **逻辑视图管理**：幂等创建（LOGICAL/MATERIALIZED）、编辑（上游/被绑定/刷新策略）、下线（DEPRECATED）。
3. **数据加工流水线**：加工任务（采集/清洗/探查/转换/UTOPIA_PUSH）注册与启停；手动触发运行——记录执行（幂等）并更新 last_run。

## 验收

- 数据源：同 ID 重复注册幂等；同名异 ID 409；非法 mode/status 400。
- 视图：创建/编辑/下线流转正确，非法 kind/status 400。
- 流水线：运行记录幂等，运行后 last_run 更新；未知任务 404；任务启停流转。
- 集成测试覆盖；前端三个页面（数据源升级、逻辑视图、数据加工）完成真实闭环。
