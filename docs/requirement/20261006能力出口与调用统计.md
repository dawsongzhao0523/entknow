# 20261006 能力出口与调用统计

## 需求描述

原型 M7「智能应用 · 能力出口」落地：

1. **能力目录管理**：能力注册（幂等）/编辑（描述、协议、负责方）/删除（连同调用日志级联清理）。
2. **调用统计真实化**：能力的历史基数（base_calls，承接 seed 假数据）+ 真实调用日志（capability_calls）合并计算总量；调用记录接口（幂等）记录 caller/状态/耗时。
3. **前端页面**：能力出口页（目录表 + 调用弹窗 + 最近调用记录），替代原型静态数字。

## 验收

- 列表调用量 = base_calls + 调用日志数（格式化展示）。
- 调用记录幂等（同 ID 不重复计数）；未知能力 404。
- 删除能力后其调用日志一并清理（事务）；重复注册幂等。
- 集成测试覆盖；前端完成真实闭环。
