# 20261006 知识库与同义词治理

## 需求描述

原型 知识运营「知识运营」的落地：

1. **知识库**：按业务领域组织的知识条目（业务模式、术语表、SOP、流程与角色），给业务专家用业务语言描述。需要条目 CRUD 写路径：幂等创建、乐观并发编辑（版本冲突 409）、软删除（已失效）、发布（待评审→已评审）。
2. **领域树**：条目按领域分层（供应链→采购/计划…），领域带条目计数。
3. **同义词治理**：AI 归并建议的专家确认闭环——选定标准词归并（幂等；已归并组换标准词归并返回 409），归并结果写回。

## 验收

- 条目创建幂等（同 ID 返回既有）；编辑带 expectedVersion，冲突 409 不落库；软删除后条目仍在库但状态「已失效」，重复删除幂等。
- 领域树接口返回正确计数；条目可按领域/关键字过滤。
- 同义词归并幂等；已归并组再次以不同标准词归并 → 409。
- 集成测试覆盖以上；前端 知识运营 两个页面（知识库、同义词治理）完成真实闭环。
