# 需求草稿：角色化首页与通知中心

> 输入：用户直接指令（2026-10-07）——1) 高保真原型按角色展示不同首页内容，生产端未实现；2) 通知消息功能未实现（仅全局表 + 首页静态列表）。

## 目标（生产级）

1. **角色化首页**：按当前用户角色渲染不同视角（真实数据）：
   - 本体管理员 → 架构治理视角（本体概览 / 评审队列 / 一致性摘要）
   - 评审员 → 评审知识视角（待裁决评审 / 同义词待归并 / 收敛候选 / 最近查询）
   - 其他（数据开发/系统集成/智能体开发/只读访客）→ 运营风险视角（高风险实例 / 最近规则触发 / 管道状态 / 待审批申请）
   共享顶部统计卡（按视角取数）+ 消息通知。
2. **通知中心**：
   - 通知按人投递（to_user，空 = 全员广播）+ 每用户已读状态（notification_reads）；
   - 顶栏铃铛（未读徽标 → 弹层列表：分类点/标题/时间，点击跳转目标并标已读，支持全部已读）；
   - 首页消息列表按当前用户取数（含个人定向通知）；
   - 评审裁决通知定向给评审提出人（按姓名映射账号，映射不到广播）。

## 非目标
- 实时推送（WebSocket/SSE）——当前拉取式，刷新与切换用户时更新；推送通道为后续提案。
