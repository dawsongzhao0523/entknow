# 需求草稿：审计日志与系统日志分离

> 输入：用户直接指令（2026-10-07）——1) 当前日志把系统日志和审计日志混在一起，系统日志排查与可观测性是复杂领域；2) 审计日志与系统日志权限不应相同；分离开，用不同 tab 管理。

## 目标（生产级）

1. **数据分离**：新增 system_logs（运行时事件：组件/级别/内容/TraceID）；audit_logs 仅保留用户写操作审计（中间件自动留痕）。
2. **真实发射**：依赖巡检、绑定同步、规则执行等运行时路径自动写系统日志（非静态数据）。
3. **权限分离（API 强制 403 + 前端隐藏 tab）**：
   - 审计日志：角色权限含 governance 或 admin（治理与系统管理域可见）；
   - 系统日志：角色权限含 admin（系统管理域可见）。
   - 示例：评审员（knowledge/modeling/governance）可看审计日志、不可看系统日志。
4. **前端**：日志中心双 tab（审计日志 | 系统日志），各自过滤/分页/CSV 导出；无权限的 tab 自动隐藏；总览页「最近告警」改由系统日志派生。

## 非目标
- 日志采集管道（stdout/文件采集）、结构化字段检索引擎、日志告警规则（后续提案）。
