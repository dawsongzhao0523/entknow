# 需求草稿：其余模块功能补齐（生产级）

> 输入：用户直接指令（2026-10-07）——「同样，帮我完成其他功能模块的。」（与系统管理同标准：生产级可用、每个功能可点击、不是 demo）

## 现状

## 目标（生产级 = 真实 API + 持久化或确定性派生，无静态假数据）

新表：market_items / market_requests / bindings / binding_runs / onto_candidates / entity_alignments。
派生引擎（无表，确定性计算）：发布门禁检查、本体一致性检查、OWL/RDF 导出、规则执行（传播触发 + 风险分重算）、撤回对账、工作台聚合。
AI/外部引擎相关（智能建模会话、语料提取）当前以**确定性规则**实现（模板/包含/别名召回），LLM 与 Utopia 对接留作后续提案并在页面如实标注。

## 非目标

- 画布式设计器视图（生产端注册中心表格设计器已可用，画布交互后续提案）；
- 真实 LLM 建模会话与 Utopia 语料提取在线对接；
- 本体分支隔离（版本模型已覆盖演化主线，分支克隆另案）。
