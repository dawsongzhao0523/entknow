# 需求草稿：组织架构与岗位维护

> 输入：用户直接指令（2026-10-07）——
> 1) 用户表单中组织架构与岗位改为可搜索下拉；2) 组织架构为树形选择框；
> 3) 岗位为可搜索下拉；4) 增加组织维护与岗位维护界面；5) 同步组织架构/岗位分别放在各自管理 tab 下。

## 现状

生产端用户表单的部门/岗位为自由文本输入；组织与岗位无字典管理（依赖手输，无法搜索选择、无治理）。

## 目标（生产级）

1. **字典表**：org_units（两级及以上组织树，含 path 全路径）与 posts（岗位字典）。
2. **用户表单**：部门 → 组织树选择框（TreeSelect，支持按名称搜索，选中写入全路径）；岗位 → 可搜索下拉（Select）。
3. **组织维护 tab**：组织树表格（新增子组织/编辑/删除）；删除保护：有子组织或被用户引用 409；
   重命名联动更新引用用户的部门全路径；「同步组织架构」= 从现有用户的部门字符串归集合并组织树（确定性 upsert）。
4. **岗位维护 tab**：岗位列表 CRUD；被用户引用不可删 409；重命名联动用户岗位；
   「同步岗位」= 从现有用户岗位归集合并（upsert）。
5. 同步按钮仅存在于各自维护 tab（用户管理 tab 不放同步）。

## 非目标

- 外部 HR 系统在线对接（同步当前为本地归集语义，外部源接入为后续提案）。
