# 20261006 本体运行时：实例 360 与行动网关

## 需求描述

原型 本体运行时「本体运行时」落地：

1. **实例数据模型**：对象实例（如采购订单 PO20260930001）——属性值、状态机状态、风险分、时间线事件；关系实例（SUPPLY 边）留待后续。
2. **实例 360 查询**：实例列表（对象/关键字过滤）、单实例详情（含时间线，正序）。
3. **时间线追加**：写路径（幂等：同实例+同时间+同事件不重复）。
4. **行动网关**：执行行动函数（如「冻结订单」f3）——鉴权（用户须存在且具备岗位语义）、业务前置（风险分>80 必须二次确认 confirm）、执行记录落库、同一事务内追加实例时间线事件并生成通知；幂等（客户端 ID）。
5. **规则传播记录**：规则触发记录查询 + 记录接口（幂等）。

## 验收

- 实例详情含全部属性与时间线；时间线追加幂等。
- 行动执行：未知用户 400；风险分>80 未确认 400；成功执行 → 执行记录 + 实例事件 + 通知同一事务可见；重复执行幂等。
- 规则触发记录可查可记（幂等）。
