# 20261006 评审流转写路径

## 需求描述

第一个真实写路径。原型 M8「评审与发布」页面的 proto.tsx 弹窗交互（裁决、驳回）需要真实的后端落库：

1. 新建评审（对应 M3 提交评审 / M8 评审台新建）：幂等（客户端提供评审 ID，重复提交返回既有记录）。
2. 裁决：通过 / 驳回 / 撤回，带状态机校验（待评审/评审中 → 终态），乐观并发（expectedStatus 不匹配返回 409），重复同向裁决幂等重放（返回当前状态，不再变更）。
3. 裁决产生站内通知（同一事务），通知 ID 确定性生成保证幂等。
4. 生产前端 M8 评审页面替代原型弹窗。

## 验收

- 幂等：同 ID 重复创建不产生重复行；同裁决重复提交不二次变更。
- 事务：裁决成功同时生成通知；任一失败全部回滚。
- 并发：expectedStatus 不一致 → 409，不落库。
- `go test ./...` 全绿；集成测试覆盖以上场景；前端页面可完成完整裁决闭环。
