# 20261006 组织与权限管理

## 需求描述

原型 M9「组织与权限」落地：

1. **角色管理**：应用级角色（本体管理员/数据开发/评审员/系统集成/智能体开发/只读访客），每个角色带模块权限集（m1-m9 菜单键）；新建/编辑/删除；内置角色不可删；被用户引用的角色不可删（409）。
2. **用户管理**：新建（幂等）/编辑（姓名/部门/岗位/角色/状态）；账号唯一（同账号不同 ID → 409）；用户的角色必须已存在（400）；停用走状态切换（正常/停用），不物理删除。
3. **前端页面**：组织与权限页（用户/角色两个页签），替代原型假弹窗。

## 验收

- 角色删除：内置 400、被引用 409、正常删除成功；删除后用户角色校验拒绝引用。
- 用户：同 ID 重复创建幂等；同账号异 ID 409；赋不存在的角色 400；停用后登录语义失效（状态停用）。
- 集成测试覆盖以上；前端完成真实闭环。
