# 20261006 后端核心 API 与 Demo 数据

## 需求描述

原型已验证核心列表类界面（本体切换、注册中心、数据源、逻辑视图、评审、通知、用户），开始真实前后端开发：

1. 后端用 PostgreSQL 持久化原型共享 mock 中的全部实体，并提供 `/api/v1` 读 API；JSON 字段与原型 TS 接口一致，便于生产前端直接替换数据源。
2. 提供 demo 数据库：用户导入（或一键启动）即可体验完整供应链示例场景；同一份数据用于开发期集成测试。
3. 生产前端先搭骨架：shell + 核心页面直连 API，其余模块按「UI 原型先行」流程推进。

## 验收

- `make app`（或本地 go run）后，curl 各端点返回与原型 mock 一致的数据
- `go test ./...` 无库环境全绿；`make itest` 对 demo 库断言通过
- demo 可重复装载不产生重复数据
