# Proposal: reasoning-governance（推理治理与行动贯通）

## Background
评审指出事实-事理-行动三个模块各自独立，缺少语义贯通和推理结果治理。

## Goal
1. **事实-事理-行动贯通**：规则触发 → 自动关联 Action → 执行 → 回写对象属性状态
2. **推理结果治理**：每次推理的完整链路留痕（调用了哪些本体片段/命中了哪些规则/推理过程/结论），可追溯
3. **约束强度分级**：对象/关系/规则增加约束等级（强/弱/参考），Action 网关根据等级自动拦截或提示
4. **本体健康度**：定期自动化一致性检查（当前为手动触发）
