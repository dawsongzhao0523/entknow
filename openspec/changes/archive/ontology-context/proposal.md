# Proposal: ontology-context（当前本体的全局上下文与展示）

## Background
用户指令（2026-10-07）：1) 未选择本体时顶部不应显示已选本体；2) 已选择时本体管理页应高亮当前本体；3) 顶部展示逻辑需重新设计。

## 设计决策（是否保留顶栏选择器）
保留——「当前本体」是多页面共享的全局工作上下文（版本历史/详情页默认值/我的角色提示），放顶栏符合全局上下文惯例。改进为：
- **会话级状态**：当前本体迁入 Session（派生自个性化设置 defaultOnto，按用户持久化）；顶栏选择即保存，下次进入自动恢复；
- **空态**：未选择时不显示任何本体值，Select 显示占位「选择工作本体」，版本/状态/角色 Tag 全部隐藏；
- **本体管理页**：当前本体的表格行高亮（主题色浅底 + 「当前」标记），版本历史卡跟随当前本体（修正原先写死供应链的问题）；未选择时提示先选择；
- **本体详情页**：缺省取全局当前本体。

## Goal
session 增加 onto/chooseOnto；AppShell 选择器改造（空态占位、选择即持久化、条件 Tag）；
Ontologies 行高亮 + 版本历史联动；OntologyDetail 缺省取全局。

## 原型落地情况
纯生产端 UX 改进（用户直接指定行为），无规格增量。
