# Proposal: ui-visual-parity（视觉对齐修正）

## Background
用户批评（2026-10-07，属实）：此前实现按自行理解做"功能对齐"，未参照高保真 UI 视觉——消息通知即为例子（原型为 420 Drawer + 分类 Tabs + 彩色分类头像 + 未读圆点，此前做成了小气泡弹层）。

## 处置与新约定
1. 通知中心按原型重做：铃铛（Badge 偏移 [-4,4]）→ 420 Drawer（标题「消息通知」+ extra 全部已读）→ 分类 Tabs（全部/待办处理/治理任务/协同分享 + 计数）→ 条目（30px 彩色分类头像[待办#059669/治理#c9861a/协同#2d8a4e] + Badge dot + 标题粗细 + Tag 分类 + 时间 + 已读 55% 透明 + 下边框 #f1f3f5）；点击标已读并跳转。保留生产增强（服务端已读/定向标记）。
2. 首页 Hero 对齐原型：时段问候（早上好/下午好…）+ 姓名 + 岗位 · 管辖角色 · 工作本体（对象/关系数）替代自拟标题。
3. **工作约定（后续一律遵守）**：生产 UI 以原型视觉为蓝本逐像素复刻布局与样式；仅当原型数据为虚构指标时，以真实数据替换同布局，并在差异清单注明。

## 后续视觉差异清单（待逐页复刻，下一轮处理）
