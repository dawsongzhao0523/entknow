# Proposal: ai-driven-modeling（AI 驱动的本体精准建模）

## Background
评审指出 entKnow 缺少大模型驱动的自动化建模能力（书中"大模型分钟级生成标准规范本体"），当前仅有确定性规则引擎。

## Goal
1. **LLM API 接入层**：支持 OpenAI/Anthropic/本地模型三种后端，可配置切换
2. **"29句话"模板库**：7 类 29 种标准化自然语言模板，引导业务专家描述业务
3. **AI 建模**：输入自然语言场景描述 → LLM 解析 → 生成对象/关系/规则/函数 → React Flow 可视化预览 → 专家确认入库
4. **双大模型校验**：模型 A 生成 → 模型 B 审计 → 差异报告 → 专家仲裁
5. **知识萃取**：从 kb_entries 文档中自动提取候选对象/关系（增强现有隐式收敛）
